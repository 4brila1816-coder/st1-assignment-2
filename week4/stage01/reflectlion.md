# Stage 1 Reflection

Before using AI, I created a basic SmartCare appointment prototype using
Python. The program stored the patient's name, practitioner's name and
appointment time. I then improved the program by using a list, dictionary
and functions to store and display appointments.

AI helped me understand some of the limitations in my code. For example,
the program did not validate all of the information entered and did not
check whether a practitioner was already booked at the same time. The AI
also generated an alternative version of the appointment function, which
gave me another way to compare how the same problem could be approached.

The AI did make some assumptions. For example, its alternative function
returned the newly created appointment even though this was not specifically
required. Because of this, I did not assume that the AI-generated code was
automatically correct.

I verified the code by running it and testing normal and unusual inputs.
I tested a normal appointment, a blank patient name, a duplicate
practitioner and time, and None values.

The engineering work still remained my responsibility because I had to
understand the requirements, review the AI suggestions, test the program
and decide which changes were appropriate. I also made one controlled
improvement by adding validation for a missing practitioner name.
