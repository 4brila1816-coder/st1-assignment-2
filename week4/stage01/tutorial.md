# Stage 1 Tutorial Activity
## Why Software Engineering Still Matters

### Activity 1 - Think-Pair-Share

If ChatGPT or Copilot can produce a 100-line Python application very
quickly, a software engineer still needs:

1. Knowledge of programming and software design so they can understand
   and check whether the generated code works correctly.

2. The ability to understand the client's problem and requirements so
   the software actually meets the user's needs.

3. Testing and problem-solving skills so they can identify errors,
   incorrect assumptions and limitations in AI-generated code.

### Activity 2 - Is This Software Engineering?

| Scenario | Programming? | Software engineering? | Why? |
|---|---|---|---|
| A - A student writes a 50-line Python calculator. | Yes | Not necessarily | The student is writing code to solve a small problem, but may not need a full software engineering process such as requirements analysis, design and testing. |
| B - A team develops a payroll system used by 5,000 employees. | Yes | Yes | The system requires more than coding. The team needs to consider requirements, users, design, testing, reliability and maintenance. |
| C - An AI assistant generates a simple appointment application from one prompt. | Yes | Not necessarily | AI can generate the program, but the output still needs to be checked against the client's requirements, tested and evaluated by a person. |

### Activity 3 - SmartCare Problem Analysis

#### Task 1 - Identify Stakeholders

| Stakeholder | What do they need? |
|---|---|
| Clinic staff | An easy way to create, view and manage appointments. |
| Practitioners | A way to view their appointments and patient information. |
| Patients | Their appointment and personal information to be recorded correctly. |
| Clinic management | A reliable system for managing clinic information. 

#### Task 2 - Identify Current Problems

1. Patient and appointment information is stored using spreadsheets and
   paper records.

2. It may be difficult for staff to efficiently manage patient and
   appointment information.

3. It may be difficult for staff to quickly access the information they
   need.

4. Using separate spreadsheets and paper records may make managing clinic
   information less organised.

#### Task 3 - Ask Client Questions

1. What information needs to be stored about each patient and practitioner?

2. What information needs to be recorded for each appointment?

3. Should users be able to edit or cancel existing appointments?

4. Who will be allowed to access and use the system?

5. What should happen if two appointments are booked with the same
   practitioner at the same time?

### Activity 4 - Critique an AI Response

| Suggestion | Client evidence? | In scope? | Decision |
|---|---|---|---|
| Appointment management | Yes | Yes | Accept |
| Facial recognition login | No | No | Reject |
| AI diagnosis recommendations | No | No | Reject |
| Patient search | No | Unclear | Keep unverified |
| Online payment | No | No | Reject |
| Practitioner schedule view | No | Unclear | Keep unverified |
| Insurance processing | No | No | Reject |
| Automatic treatment-plan generation | No | No | Reject |

### Exit Question

A software engineer must verify that the software meets the client's
requirements. AI can help suggest solutions or generate code, but the
engineer still needs to check the requirements, test the software and
decide whether the final solution is appropriate for the client.
